# /GOAL – Projektübertragbare Skill Factory

**Parameter:** `PROJECT_NAME`, `REPOSITORY_URL`, `ASSET_DIR`, `PRIVACY_POLICY`, `TARGET_BRANCH`.

1. **Discover:** Repo, PRs, historische Dateien, PDFs, PPTX, ZIPs, Quellcode und Workflows erfassen.
2. **Inventory:** Versionsstand, Hashes, Quelle, Vertraulichkeitsklasse und Verfügbarkeit als Nachweise erfassen.
3. **Compare:** Fehlende Originale, widersprüchliche Versionen und Demo-vs.-Produktivstatus markieren.
4. **Plan:** Bestehende Skills prüfen; fehlende in `SKILL.md` + Config + Tests erstellen.
5. **Validate:** Unit-/Negativtests, Archiv-SHA-256, PDF/PPTX-Abgleich, Agentenrechte.
6. **Approve:** Datenschutz, Veröffentlichung, Hardware, PR-Freigabe getrennt behandeln.
7. **Integrate:** Branch und Draft-PR, kein automatischer Merge; Funktionserhalt und Rollback.
8. **Deliver:** Berichte, ZIP, PPTX, PDF, Agenten-/Skill-Katalog, reproduzierbare Startbefehle.

Kein automatischer Zugriff auf andere Projekte oder externe Agentenplattformen ohne deren ausdrückliche Verbindung.
