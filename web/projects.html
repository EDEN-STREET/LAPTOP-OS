EDEN Projekte · Kanban

Eigene Projektbereiche für Wiki, Handbuch und LAPTOP-OS; ROUTER und PIXEL bleiben als Folgestrecken sichtbar. Aufgaben lassen sich in vier Spalten planen, verschieben und lokal exportieren.

Nur lokaler Kanban-Prototyp: Projektkarten bleiben in diesem Browserprofil (localStorage). Keine GitHub-Projects-Verbindung, kein Cloud-Sync, keine automatischen Systemaktionen. Keine Passwörter oder privaten Falldaten eingeben.

Aufgabe hinzufügen

Verbindlicher Abnahme-Workflow

Quelle → Plan → Preflight → Implementierung im Feature-Branch → Tests → Review → Freigabe → Merge → Nachprüfung → Dokumentation/Rollback. Status Erledigt im lokalen Board ist eine manuelle Aufgabenkennzeichnung, kein automatischer technischer Prüfbeleg.
